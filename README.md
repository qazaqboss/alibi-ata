# Әліби Қойлыбаев (1932–2018)

Сайт-история о жизни Әліби Қойлыбаева, директора совхоза имени Шевченко в Карабутаке, депутата Верховного Совета Казахской ССР и автора книги «Бабамнан қалған байтағым».

Разделы: родословная, жизнеописание, напутствие потомкам (цитаты из книги), история Иргизского и Карабутакского края, трудовой путь, награды, книга, газетные публикации.

Основной источник: Әліби Қойлыбаев, «Бабамнан қалған байтағым» («Родная земля, оставшаяся мне от предков»), Актобе, 2012 (русский перевод, 2026).
